# every request (see basic_memory_agent._load_persona_examples).
#
# Measured on MiniCPM5-2B with ctest/probe_identity.py (identity-attack set,
# 3 samples x 5 questions):
#   system prompt alone              3/15 breaks
#   system prompt + anchor rule      2/15
#   system prompt + these examples   1/15
#
# Three rules when editing this file:
#
#   1. Only emotion tags that exist in the Live2D model's emotionMap.
#      mao_pro has: neutral anger disgust fear joy smirk sadness surprise.
#      The model invents [laugh]/[grin]/[thought]/[teary eyes] constantly;
#      unknown tags silently fail to move the face.
#
#   2. Never write a negative example ("不要说X").  Measured: it activates
#      the very pattern it forbids.  Give the behaviour you want instead.
#
#   3. Do NOT give model answers to questions viewers actually ask in chat
#      (weather, jokes, "喜欢什么"...).  Measured: the model copies those
#      lines verbatim and every viewer gets the same reply -- the tell is
#      worse than breaking character.  Only pin down responses that must be
#      consistent: identity challenges and tone.  Keep the *questions* here
#      slightly unusual so there is nothing worth copying.
